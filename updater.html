OHR 데이터 갱신기

공홈이 프로그램 접근을 막아서, 공홈을 연 브라우저가 대신 목록을 읽어서 깃허브에 올리는 방식이에요. 계산기 사이트는 깃허브에 올라간 pets.json과 items.json을 알아서 가져가요.

1. 처음 한 번만
  1. 아래 버튼을 클릭하지 말고 즐겨찾기 바로 끌어다 놓기 (즐겨찾기 바가 안 보이면 Ctrl+Shift+B)
  2. 깃허브 토큰 만들기: github.com 프로필 > Settings > Developer settings > Fine-grained tokens > Generate new token
    · Repository access: Only select repositories > llumixxx/OHR
    · Permissions > Repository permissions > Contents: Read and write
    · 만들어진 토큰(github_pat_...)을 복사해두기

OHR 갱신

2. 갱신할 때마다
  1. 공홈에 로그인하고 갱신할 페이지 열기: 펫은 페트정보 페이지, 아이템은 아이템 페이지
  2. 즐겨찾기의 OHR 갱신 누르기 (오른쪽 위에 창이 떠요. 열린 페이지에 맞는 창이 떠요)
  3. 처음이면 토큰을 붙여넣기 (그 브라우저에 저장돼서 다음부턴 안 물어봐요)
  4. 먼저 확인만을 눌러서 개수가 맞는지 보고, 괜찮으면 갱신 시작

· 공홈에는 천천히 요청해요 (페이지마다 0.7초 쉬어요)
· 처음에는 이미지를 같이 저장하느라 몇 분 걸려요
· 바뀔 게 있을 때만 깃허브에 저장해요
