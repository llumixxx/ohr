# OHR 환각 계산기

오르서버 펫의 레벨 1 초기치로 가능한 등급과 +8 환각 확률을 계산해요.

## 파일
- `index.html`, `style.css`, `app.js` : 계산기 화면
- `pets.json` : 펫 데이터 (아직 없어요. 이 파일이 있어야 펫 목록이 나와요)

## 보는 방법
GitHub 저장소의 Settings > Pages 에서 Branch를 `main`, 폴더를 `/ (root)`로 고르면 주소가 생겨요.

## pets.json 형식
펫 하나가 배열 한 칸이에요.

```json
[
  {
    "id": "1",
    "name": "예시펫",
    "variant": "일반",
    "attrs": [["지", 8], ["수", 2]],
    "obtain": "획득 방법",
    "growthS": [10.0, 2.0, 1.5, 1.5],
    "initS": [50, 10, 8, 8],
    "origin": [25, 25, 20, 25],
    "k": 20,
    "rideable": false,
    "imageUrl": "이미지 주소"
  }
]
```

- `growthS` : S급 참고 성장률 (내구, 공격, 방어, 순발)
- `initS` : S급 참고 초기치 (내구, 공격, 방어, 순발)
- `origin` : 원본계수 4개, `k` : 초기치 비율
- 환생이나 진화한 펫은 `name`은 같게 두고 `variant`만 다르게 넣어요 (일반, 환생, 진화, 환생·진화).

## 계산 방식
레벨 1 초기치에서 등급 보정(−2~+2)과 보너스 분배 10포인트의 모든 경우(178,750가지)를 대조해서, 맞는 조합의 등급 분포로 확률을 구해요. 가능한 조합은 모두 같은 비율로 봐요.
